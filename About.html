About the project

Why Recipe Finder Was Created

Recipe Finder is a class project designed to make discovering and sharing simple meals fast and easy.

Project Goals

  • Help users search recipes by name, ingredient, or instruction.
  • Allow users to add recipes through a validated HTML form.
  • Provide a responsive experience on desktop, tablet, and mobile screens.
  • Use accessible labels, alternate text, semantic HTML, and strong color contrast.
  • Demonstrate JavaScript DOM updates and local browser storage.

Ethical and Legal Considerations

The project avoids collecting real sensitive information. In a production version, passwords would be hashed on a secure server, communication would use HTTPS, and a privacy policy would explain how user data is collected and used.

Recipe images and written content should be original, licensed, or used with permission. Accessibility is supported through keyboard-friendly controls, readable contrast, labels, and descriptive alternate text.
